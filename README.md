📋 Sobre o Projeto

Radiant Barber é uma landing page imersiva desenvolvida para uma barbearia com temática tática inspirada na identidade visual do jogo Valorant. O projeto foca em uma experiência visual de alto impacto ("Glitch aesthetic"), performance e conversão de agendamentos, transportando o cliente para uma atmosfera de "agente de elite".

✨ Funcionalidades Principais

Design Tático & Responsivo: Layout agressivo utilizando a paleta oficial (#ff4655, #0f1923), tipografia (Anton/Oswald) e geometria assimétrica.

Menu Mobile Interativo: Navegação lateral (Overlay) funcional para dispositivos móveis.

Animações FX:

Efeito Glitch no título principal.

Loading Screen personalizada com animação de pulso.

Transições de hover em cards e botões com clip-path (cortes geométricos).

Galeria Dinâmica: Exibição de agentes (barbeiros) com efeitos de zoom e escala.

Backgrounds Imersivos: Uso de texturas de grid e imagens de alta resolução com sobreposição tática.

🛠️ Tecnologias Utilizadas

Este projeto foi construído focado em performance pura e manipulação de DOM:

HTML5: Estrutura semântica.

Tailwind CSS: Estilização utility-first via CDN para design rápido e responsivo.

JavaScript (ES6+): Lógica para o menu mobile, tela de carregamento e interações de scroll.

FontAwesome: Ícones vetoriais.

Google Fonts: Fontes Anton e Oswald para identidade visual.
